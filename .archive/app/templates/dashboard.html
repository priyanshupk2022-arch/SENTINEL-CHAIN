1-Line Drop-in Proxy Quickstart

Route OpenAI, Anthropic, LangChain, or custom LLM traffic through Aegis with zero code changes

Python (OpenAI SDK Integration)

from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8000/v1",
    api_key="aegis_live_your_key_here"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Analyze confidential report"}]
)
print(response.choices[0].message.content)

cURL Terminal Drop-in

curl http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer aegis_live_your_key_here" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Secure my customer data"}]
  }'
